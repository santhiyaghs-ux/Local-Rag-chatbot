# Local RAG Chatbot

A local AI-powered chatbot that answers questions based on uploaded PDF documents using Retrieval-Augmented Generation (RAG).

## Features
- Upload PDF documents
- Ask questions about document content
- Retrieve relevant information to generate answers
- Run the application locally

## Tech Stack
- Python
- Retrieval-Augmented Generation (RAG)
- Libraries listed in `requirements.txt`

## Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/santhiyaghs-ux/Local-Rag-chatbot.git
   ```
2. Open the project folder:
   ```bash
   cd Local-Rag-chatbot
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Follow the instructions in the application code to configure any required model or API settings.
5. Run the application using the appropriate command for your project.
